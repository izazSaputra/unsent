# Unsent

The portfolio of **Izaz Saputra**, a frontend developer from Malang, Indonesia.

> A collection of letters that were never sent — until one finally is.

Unsent is written in two languages: prose and code. Each sentence on the page has its source underneath, and a reading lens lets visitors look through the prose to the code that renders it. The site ends with an epilogue where, for the first time, a letter actually gets sent: a message from the visitor.

> **Status:** v3 is being rebuilt on the `arc-unsent` branch. The design spec and implementation plan are in [`docs/superpowers/`](docs/superpowers/).

## Built with

- [React 19](https://react.dev) + [Vite](https://vite.dev)
- [GSAP](https://gsap.com) (ScrollTrigger, SplitText) for motion
- [Lucide](https://lucide.dev) icons

## Run it locally

Requires Node.js 20 or newer.

```bash
npm install
npm run dev       # start the dev server at http://localhost:5173
npm run build     # build for production into dist/
npm run preview   # preview the production build
npm run lint      # lint the source
```
